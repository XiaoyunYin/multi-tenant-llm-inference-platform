# Related serving systems

llm-d describes serving and routing components for Kubernetes. See the
[pinned llm-d v1.0.0 documentation](https://github.com/llm-d/llm-d/tree/v1.0.0/docs).

SGLang describes an inference runtime and its supported serving paths. See
the [pinned SGLang v0.5.23 documentation](https://github.com/sgl-project/sglang/tree/v0.5.23/docs).

The gateway evidence covers the documented workloads and versions in this
repository. There is no cross-system performance ranking.
